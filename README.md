# QUATT Catalog V2 — GitHub + Supabase + Cloudflare Pages

Эта версия собрана на базе исходников старого QUATT Catalog, но **без зависимости от ChatGPT Sites**.

## Сохранено из оригинала
- чёрная шапка QUATT / жёлтый акцент;
- категории;
- поиск;
- фильтр бренда;
- максимальная цена;
- сортировка по цене;
- карточки товаров;
- режим клиента;
- внутренняя закупочная цена / поставщик / заметки;
- до 5 фото;
- быстрые проценты наценки;
- ручная наценка;
- добавление категорий;
- роли Владелец / Администратор / Продавец;
- мобильная версия.

## Изменено
Старое:
- ChatGPT Auth
- Cloudflare D1
- Cloudflare R2

Новое:
- Supabase Auth
- Supabase Postgres
- Supabase Storage
- GitHub
- Cloudflare Pages

## Важно: сначала Supabase

1. Открой Supabase → SQL Editor.
2. Открой файл `SUPABASE_SETUP_V2.sql`.
3. Вставь весь SQL и нажми Run.
4. Проверь, что запрос завершился без ошибки.
5. В Authentication → Users должен быть твой пользователь `guw.taurus@gmail.com`.

SQL **не добавляет товары**. Тестовый товар из старого каталога не переносится.

Подключи репозиторий через Pages.

Это статический сайт, сборка не требуется:
- Framework preset: None

## Вход и роли

- Владелец: `guw.taurus@gmail.com`
- Администратор: может добавлять/редактировать товары, фото и категории.
- Продавец: видит только клиентскую часть.
- Без входа: посетитель видит публичный каталог.

Владелец может управлять сотрудниками в разделе «Доступ и категории».

## Безопасность

`config.js` содержит только Supabase anon key. Его разрешено использовать в браузерном приложении.
Не добавляй `service_role` key в сайт.

Приватные поля (закуп, поставщик, контакты, заметки) **не выдаются публичным посетителям**:
публичный каталог работает через RPC `get_public_products()`.

## Телефон

Сайт адаптирован для мобильного браузера.
Администратор может:
- войти;
- добавить товар;
- сфотографировать товар камерой;
- загрузить до 5 фото;
- поменять цену и наценку;
- редактировать категории.

Также есть PWA-заготовка для добавления сайта на главный экран.
